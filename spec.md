A kid game with pictures of animals and sounds with following game flow:
0. it is on reactJs
1. it runs in a browser and uses native text-to-speech tool (or whatever the name is)
2. in a first mode it shows a picture of an animal and says e.g. 'the cow says "muuuu"', then I can swipe to the left/right or use a button to show the next picture.
3. in a second mode it shows a picture and asks 'what does the cow say?' then captures the sound and checks if it contains "muuu", then I can swipe to the left/right or use a button to show the next picture.
4. the animals are pictures in a folder on a disc
